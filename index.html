工具簡介

這是一個透過瀏覽器書籤載入的 JavaScript 小工具。進入遊戲頁面後，點選你建立的書籤，即可載入外部腳本並顯示管理面板。

工具需要遊戲頁面本身已載入相關資料與函式；若遊戲更新了內部程式，部分功能可能失效。請只在你理解並接受遊戲規則與風險的情況下使用。

提醒：修改遊戲資料可能影響存檔、遊戲平衡或帳號狀態。建議先確認遊戲規範，並自行承擔使用風險。

功能一覽

01｜龍鑽將龍鑽數量設定為指定的大額數值。
02｜金幣將金幣數量設定為指定的大額數值。
03｜背包物品將支援的物品數量調整為 900,000,000。
04｜六項基本能力將六項基本能力數值設定為 100。
05｜武器／防具強化將支援的武器與防具強化等級設定為 +15。
06｜飾品強化將支援的飾品強化等級設定為 +5。
07｜時間偏移調整頁面使用的 Date.now() 回傳時間，偏移約 24 小時；可能影響依賴時間的遊戲邏輯。

實際執行結果仍取決於目前遊戲版本、資料載入狀態與腳本相容性。

Android Chrome 安裝教學

  1. 先在 Chrome 開啟任意網頁，點選右上角「⋮」並加入書籤。
  2. 開啟書籤管理，找到剛才建立的書籤，點選編輯。
  3. 將書籤名稱改成「日出之國工具」。
  4. 把下方的書籤程式碼完整貼到「網址」欄位，取代原本網址，然後儲存。
  5. 進入日出之國遊戲頁面，確認遊戲已載入，再從網址列輸入書籤名稱或從書籤清單點選它。

若手機版 Chrome 不方便直接點書籤，可在網址列輸入「日出之國工具」，從自動完成的書籤項目中點選。

常見問題

點選書籤後沒有反應？

確認你是在遊戲頁面執行、遊戲已完成載入，並確認手機網路可連線到 jsDelivr。也可重新整理遊戲後再試。

顯示「載入失敗」怎麼辦？

請先確認網路連線正常，並確認書籤程式碼已完整貼入書籤的「網址」欄位。重新整理遊戲頁面後，再試一次。

顯示「版本標記不符」怎麼辦？

代表載入後沒有讀取到預期的版本標記。請確認目前使用的是安裝網頁最新提供的書籤碼，並重新整理遊戲後再試。如果仍然發生，請回報目前使用的版本標記。

遊戲更新後工具不能用了？

遊戲更新可能更動內部資料結構或函式名稱，造成腳本不相容。需要依新版遊戲重新檢查並更新腳本。

工具之後更新，需要重新加入書籤嗎？

目前使用固定版本網址。若工具更新到新的 GitHub 版本，需要同步更新本頁的啟動書籤碼，再重新複製到瀏覽器書籤。
